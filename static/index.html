💬 白话解读（看不懂数字就从这里开始）

🌍 各国宏观动能分（0-100）

评分 = GDP增速 + 居民消费增速 − 通胀惩罚（通胀超2%部分折半），按组内 min-max 归一。分数高 ≈ 该市场钱包在变大。

📈 品类需求趋势（近12个月 vs 前12个月）

需求代理指标：维基百科相关词条浏览量（免费接口），预留 Google Trends 适配器可升级。抗萧条β：绿色=下行期受益，红色=反例对照。

🎯 机会点矩阵（Top 15）

得分 = 宏观动能 × 抗萧条β × 需求趋势。解读方式：高分机会 = 钱在变多的市场 × 萧条里反而涨的品类。仅是筛选起点，动手前仍需 1688 供给端查重与预售页验证。

🩺 民生温度计 · 生产型硬数据（真实行政记录，非调查问卷）

与GDP/CPI等"汇总统计口径"不同，下面每个数都来自真实个体事件（失业金理赔单）或雇主税务申报记录，是更难注水的生产型数据。美国口径先行为示范（周更），可在 app/sources.py 的 FRED_SERIES 按同一接口扩展各国序列。

👥 分群画像（按年龄段切市场：证据数字 → 推断需求）

开放数据只能切到 15-24 / 15-64 / 65+ 三段（5岁组细分在付费报告如 Euromonitor 或 UN WPP 中）。解读方法：先看证据列的交叉验证（人口结构×失业×消费），再看推断需求——推断只是假设，落地前必须访谈 20+ 个该群体真人。
